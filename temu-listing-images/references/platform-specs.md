# 平台规格总表

> 平台规则会调整，**上架前以卖家后台最新公告为准**。下表为常见基线值。

## 一、Temu（本 Skill 主平台）

| 规则项 | 基线 |
|---|---|
| 比例 | **1:1 正方形（强制，无一例外）** |
| 尺寸 | ≥800×800，建议 1200 以上 |
| 主体占比 | 70–85% |
| 背景 | 浅色纯色/干净，不可杂乱、不可抠图假背景 |
| 文字 | 主图不带中文、水印、二维码、拼接、边框、促销贴图 |
| 格式 | JPG / JPEG / PNG，sRGB |
| 体积 | 单张 ≤2MB（以后台为准，部分类目 ≤3MB） |
| 张数 | ≥5 张，不可重复凑数 |
| 变体 | SKU 图与实际颜色一致，首个 SKU 首图影响 SPU 首图 |
| AI 标注 | 逐步要求标注，保留生成记录 |

服饰类轮播图另有 3:4 规格（≥1340×1785）——**属另一套要求，需用户确认后单独出**。

## 二、Amazon

### 主图（白底）

| 规则 | 值 |
|---|---|
| 背景 | 纯白 RGB 255,255,255（#FFFFFF） |
| 主体占比 | **≥85%** |
| 尺寸 | 长边 ≥1000px 可缩放；**推荐 1600–2000px**；上限 10000px |
| 格式 | 优先 JPEG（也接受 TIFF/PNG/GIF），sRGB |
| 内容 | 只能有在售产品；不得加文字、徽标、边框、水印、道具、额外物品 |
| 呈现 | 完整可见、对焦清晰、颜色真实；服装可用平铺/模特（按类目规则） |

Walmart / eBay / Shopee 的主图规则类似——用同一产出，再按平台比例裁切。

### 副图 / 卖点图（2–7）

- 2000×2000（1:1），允许文字
- 禁用无法证明的宣称（"#1"、"best"）、禁止出现竞品名
- 可读性：标题 ≥7% 画面高，正文 ≥3.5%，单图 ≤12 词，对比度 ≥4.5:1

### 多角度套图

- 最多 9 张（桌面端展示 7 张），1:1
- 必须给模型**每一个真实角度**（正面/背面/侧面/Logo 特写），它无法凭空知道背面长什么样

### A+ 模块尺寸（Basic A+）

| 模块 | 尺寸 (px) |
|---|---|
| 标准图文页眉 | 970 × 600 |
| 标准公司 Logo | 600 × 180 |
| 图文叠加（深/浅色文字） | 970 × 300 |
| 单图 + 侧栏 | 300 × 400（主） / 350 × 175（侧） |
| 四图 + 文字 | 220 × 220 ×4 |
| 三图 + 文字 | 300 × 300 ×3 |
| 对比表 | 150 × 300（每商品） |
| 单左/右图 | 300 × 300 |
| 品牌故事背景 | 1464 × 625 |
| Premium A+ 全幅 | 1464 × 600（桌面） / 600 × 450（移动） |

约束：单图 ≤2MB；JPG/PNG；**不得含价格、促销、物流承诺、竞品引用**；图内文字须同步写进 alt text。

### Store / 广告

| 位置 | 尺寸 |
|---|---|
| Store hero | 3000 × 600（最低 1500 × 300） |
| Sponsored Brands 自定义图 | 1200 × 628 |

## 三、淘宝 / 天猫

| 项目 | 规格 |
|---|---|
| 主图 | 1:1，800×800+ |
| 详情长图 | **750 px 宽**，每屏约 750×1000；单片 ≤1546 高；JPG |
| 主图数量 | 5 张（1 白底/场景首图，2–4 卖点，5 白底供搜索） |
| 卖点文案 | 卖点 ≤3 条，首图避免"牛皮癣"式堆字 |

**广告法**：避免"最/第一/国家级/绝对"等用语；"保温 24h""食品级"这类宣称必须可证明。

## 五、Shopee / Lazada / TikTok Shop

| 项目 | 规格 |
|---|---|
| 商品主图 | 1:1（白底或干净场景）+ 4–8 张卖点/场景 |
| Shopee 店铺 Banner | 2000 × 600（桌面）、1200 × 1200 / 1:1 轮播 |
| Lazada 店铺 Banner | 1200 × 500（约） |
| TikTok Shop 店铺 Banner | 1:1 或 3:1（按店铺装修编辑器） |
| 服饰/模特图 | 1:1 或 3:4 |
| 文案 | 使用目标市场本地语言 |

## 六、小红书

| 项目 | 规格 |
|---|---|
| 比例 | **3:4**，推荐 1080×1440（出 1024×1536 再裁） |
| 标题 | ≤12 个中文字，占画面高 ≥20%，缩略图下可读 |
| 禁用 | "最/第一/绝对/全网最低"等硬销词、二维码、电话、站外平台名 |
| 风格 | 真实感优于明显 AI 渲染——用自然光、允许轻微不完美 |

## 七、Shopify / 独立站

- PDP 场景图：4:5（1600×2000）或 1:1，留 10% 安全边距供裁切
- 整套图保持同一比例

## 八、场景图 / 社媒

| 用途 | 比例 |
|---|---|
| Amazon 副图场景 | 1:1，2000×2000（可带少量文字，产品仍是主角） |
| 社媒 feed | 4:5 |
| Stories / 竖版 | 9:16（上下各留 14% 避开 UI） |

## 九、Banner 通用尺寸

| 位置 | 尺寸 (px) |
|---|---|
| 淘宝天猫 PC 首焦 | 1920 × 600–900（安全内容宽 990/1200） |
| 淘宝天猫无线首页 | 750 × 300–950 |
| Meta / TikTok feed 广告 | 1080 × 1080、1080 × 1350、1080 × 1920 |

**关键文案放在画面中央 80% 区域**，各平台店铺编辑器会裁边。尺寸变动频繁，从更大的尺寸出图再裁。
